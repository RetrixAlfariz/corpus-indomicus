# v1 completion contract

Corpus Indomicus v1 is considered complete when a user can create and maintain a bounded recent legal corpus without manually managing BPK pages.

## Default pilot

- source: JDIH BPK
- range: 2025 through the run's current year
- cutoff: the manifest is finite once discovery finishes
- originals: PDF source bytes are retained in v1 as ground truth for v2

## Delivered capabilities

- configuration/setup
- range or `--all` finite snapshot backfill
- per-year discovery checkpoints and automatic resume
- persisted manifest items and retryable failure state
- incremental sync with a configurable overlap window
- determinate processing progress bar backed by the manifest
- source-record, legal-instrument and SHA-256 object identity separation
- exact object deduplication
- compact lossless HTML/JSON/text storage
- PDF signature/MIME validation
- neutral cross-document reference observations
- storage safety reserve
- corpus/PDF/storage metrics
- object integrity verification
- low-level BPK development commands retained for debugging

## Intentionally deferred to v2

- PDF text-layer inspection and extraction
- OCR
- layout reconstruction
- canonical document AST
- Markdown rendering
- semantic legal-relation interpretation
- source-blob eviction policy based on representation fidelity

The v1 pilot corpus is the validation ground truth for those v2 features.
